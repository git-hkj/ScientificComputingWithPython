# Scientific Computing with Python

## Basics
https://www.flowthermolab.com/courses/scientific-computing-with-python/

The course covers all the major topics in Python from a scientific computing perspective. The course covers:
- Python basics and using Python interactively as a calculator
- Strings, variables, and writing/saving Python programs
- Core data structures: lists, tuples, and dictionaries
- Control flow: for loops, while loops, if statements, break, and continue
- Functions, including positional and keyword arguments
- Pass-by-value vs pass-by-reference concepts
- Introduction to object-oriented programming with classes and objects
- Creating and importing Python modules
- Scientific computing libraries:
    - NumPy for numerical computing
    - SciPy for scientific and mathematical computations
    - Matplotlib for data visualization and plotting

By the end of the course, learners should be able to:
- perform complex calculations
- handle and analyse data
- visualize results
- delve into advanced topics such as scientific packages and OOP

Course has 28 lessons along with assignments.

## Numpy
https://www.flowthermolab.com/courses/python-advanced-numpy/

The course focusses on unlocking th e full potential of NumPy- Python's core library for numerical computing. This course dives deeper into high performance numerical operations and scientific workflows using NumPy. The course covers how to:
- Create and manipulate NumPy arrays
- Index and slice multi-dimensional datasets
- Use broadcasting for operations on arrays of different shapes
- Perform matrix algebra and statistical computations
- Work with Fourier transforms
- Optimise numerical code using in-place operations and custom ufuncs
- Integrate NumPy into larger scientific and machine-learning workflows

By the end of the course, learners should be able to:
- Confidently work with NumPy arrays.
- Apply broadcasting and vectorised operations efficiently.
- Perform common scientific-computing tasks directly in NumPy.
- Improve performance of numerical applications.
- Build a foundation for more advanced scientific-computing and machine-learning libraries.

Course has 14 lessons along with assignments.
